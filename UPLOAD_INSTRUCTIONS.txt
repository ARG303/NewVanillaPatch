NewVanilla Patch v0.8.9 compatibility support hotfix

Upload these paths to the ROOT of the existing GitHub repository in ONE commit:
  LAUNCHER_VERSION
  launcher/RA3FPSLauncher.exe
  installer/NewVanillaPatch_Setup.exe
  compatibility/ra3_40023_to_29aa.r3dp
  compatibility/ra3_ec230_to_40023.r3np
  .github/workflows/update-manifest.yml

DO NOT replace MOD_VERSION or mod/NewVanilla.zip. Keep the current NewVanilla mod version.

After push, wait for Actions -> Update manifest to finish successfully.
The workflow will rebuild manifest.json from the actual repository files and include both compatibility support files.

v0.8.9 also installs the compatibility .r3dp/.r3np files locally, so users who install v0.8.9 do not depend on the first GitHub support-file download for these known RA3 builds.

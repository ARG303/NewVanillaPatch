NewVanilla Patch v0.8.8 — GitHub launcher hash hotfix

WHY THE SCREENSHOT ERROR HAPPENS
The manifest says one SHA-256 for launcher/RA3FPSLauncher.exe, but GitHub is serving a different EXE. Older launchers refuse the update correctly because the SHA-256 does not match.

UPLOAD THESE 4 FILES TO THE SAME PATHS IN ONE COMMIT:
  LAUNCHER_VERSION
  launcher/RA3FPSLauncher.exe
  installer/NewVanillaPatch_Setup.exe
  .github/workflows/update-manifest.yml

IMPORTANT
- Do NOT manually type the launcher SHA into manifest.json.
- Do NOT replace MOD_VERSION or mod/NewVanilla.zip.
- Let the Update manifest GitHub Action rebuild manifest.json from the exact committed EXE.
- Wait until the GitHub Action finishes successfully before testing an old launcher.
